**[Quizit](https://quizit.online)** is an AI study assistant that brings answers from 12+ educational platforms into one place - in the browser, in the extension, or in the AI chat.

## Get Quizit

- 🌐 **Web** open [quizit.online](https://quizit.online), no install needed
- 🧩 **Browser extension** [Chrome Web Store](https://chromewebstore.google.com/detail/quizitonline/gbihgipgiggdfncfhinohincfbieonkf) for Chrome, Edge, Brave and Opera
- 💬 **AI chat** ask about any question at [chat.quizit.online](https://chat.quizit.online)
